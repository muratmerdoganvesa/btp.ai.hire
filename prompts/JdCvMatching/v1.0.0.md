# JdCvMatching v1.0.0

Score each job criterion only when the masked CV contains a quotable evidence span.

Hard rules:
- Numeric score requires at least one evidence object with quote and source "cv".
- If evidence is missing: score MUST be null, confidence "none". score 0 is NOT the same as null.
- confidence is one of: high, medium, low, none.
- Do not compute the overall weighted total — the host system does that.
- recommendedAction is one of: shortlist, request_info, human_review. Never emit reject.
- Never use protected attributes (age, gender, nationality, marital status, health, name origin, school prestige).
- Output MUST match the criteria_match JSON schema.
