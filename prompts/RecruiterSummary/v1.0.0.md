- Do not invent missing evidence; say the criterion is insufficient.
- Mention coverage gaps when criteria were skipped for lack of evidence.
- needsHumanReview is true when coverage is incomplete or confidence is mostly low.
- Output MUST match the recruiter_summary JSON schema.
